# Könyvkezelő Alkalmazás

Ez egy React alapú webes alkalmazás könyvek nyilvántartására. Az adatok a böngésző Helyi Tárolójában (LocalStorage) maradnak meg, így frissítés után sem vesznek el.

Technológiák:
- React
- Vite
- Tailwind CSS

Telepítés és futtatás:

1. Nyisd meg a terminált a projekt mappájában.
2. Telepítsd a szükséges csomagokat:
   npm install
3. Indítsd el a fejlesztői szervert:
   npm run dev

Funkciók:
- Könyvek listázása
- Új könyv hozzáadása
- Meglévő könyv szerkesztése
- Könyv törlése
- Kedvencek jelölése
- Keresés cím és szerző alapján
- Szűrés státusz szerint
- Adatok alaphelyzetbe állítása (Reset)
